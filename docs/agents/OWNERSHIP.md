# VIRO Studio — Agent Ownership Map

One active delivery packet has one implementation owner. Parallel owners may not edit the same production file.

| Squad / owner | Primary responsibility | Normal production paths |
|---|---|---|
| Editor Core | document model, command bus, undo/redo, transforms, selection, grouping, alignment, persistence invariants | `src/document/**`, core editor portions of `src/app/**` |
| Canvas & Rendering | CanvasKit compositor, rendering fidelity, hit-testing/render transforms, thumbnails, visual performance | `src/engine/**`, compositor/render-specific modules |
| Typography | HarfBuzz shaping, type model/editor, font registry/import, text rendering/export fidelity | typography/font modules under `src/**`, related tests |
| UI/UX | desk chrome, panels, menus, tools, interaction wiring, accessibility, design-system fidelity | `index.html`, `src/chrome/**`, UI CSS/modules |
| Assets & Import | asset library, placement, PSD/VDJ/image import, user assets | `src/library/**`, importer modules |
| Export | PNG/PDF/SVG or other truthful export paths and fidelity | export modules + export tests |
| AI | real model-backed editing/generation capabilities only; availability gating | model/inference modules; never fake service UI |
| Platform | auth, cloud persistence, sync, tenancy, billing/entitlements, deployment | platform/service modules, Edge/backend config, deploy config |
| Verification | tests, evidence generation, QA harness; may add tests but not repair production implementation during verification | `tests/**`, QA scripts |
| Research/Architecture | evidence gathering, ADR/RFC proposals only when requested/blocked | `docs/research/**`, `docs/adr/**` |

## Shared files

`src/app/**`, `index.html`, package manifests, build config, and central types are collision-prone. When two packets need a shared file, Governor must either:

1. serialize the packets; or
2. designate one packet as integration owner and keep the other packet read-only on that file.

## Scope discipline

A squad may inspect any code necessary to understand dependencies. It may edit only paths authorized by the delivery manifest.

If a correct solution requires another domain:
- stop;
- record the exact cross-domain dependency;
- return `BLOCKED` to Governor;
- do not quietly expand scope.

## UI changes generated by non-UI squads

A functional squad may make the minimum UI wiring needed to expose its capability only if the manifest names those UI paths. Material visual redesign belongs to UI/UX and requires Critic review.

## Test ownership

Builders add tests for their work. During VERIFY, the Verifier may add an independent regression/edge-case test that demonstrates a failure, but it must not patch the production code. Once rejected, ownership returns to the Builder.
